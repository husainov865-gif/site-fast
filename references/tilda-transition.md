# Передача после Figma
Последовательность обязательна: проверенный согласованный ZIP → инструкция пользователя по подключению MCP/ключей и её установочный промпт → доступные инструменты MCP → отдельный промпт вёрстки → создание новой страницы → приёмка. Полный текст промпта: зарегистрированный modules/tilda/references/conversation.md. Не придумывать установочный промпт MCP; его пишет автор пакета. Если авторская инструкция ещё не приложена, честно указать, что этот шаг ожидает владельца. При уже подключённом MCP пропустить повторную установку. Явный перенос не равен публикации.
