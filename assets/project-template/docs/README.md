# Документы работы

Агент создаёт здесь materials-inventory.md при подготовке материалов, затем brief.md, design-decisions.md, checks.md и deployment.md по мере работы. История двух основных документов — в materials-history/. migration.md нужен только при переносе.

Основные требования находятся в корне проекта в «Структура сайта.md» и «Фирменный стиль.md». Служебные сводки не должны становиться конкурирующей копией задания. В reports/ сохраняются JSON-отчёты и скриншоты; PROJECT-STATE.md хранит этап, готовность и согласования.
