# Исходные материалы

Агент сохраняет здесь доступные оригиналы брифов, брендбуков, структур, текстов, изображений и других материалов. Пользователь может передавать их в чат или складывать сюда самостоятельно. Отдельной обязательной анкеты нет.

По материалам агент создаёт в корне проекта два основных документа: «Структура сайта.md» и «Фирменный стиль.md». Оригиналы не заменяются этими документами и не изменяются. Список источников и ограничения чтения записываются в docs/materials-inventory.md. Пароли и приватные ключи здесь не хранятся.
