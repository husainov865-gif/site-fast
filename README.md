# site-fast

Базовый скилл: подготовка материалов, HTML-макет и размещение сайта на сервере.

Этот репозиторий содержит рабочие правила агента, установщики, инструменты, шаблоны и тесты. Пользовательская инструкция и стартовый промпт выдаются отдельно в Telegram.

## Точки входа для агента

Прочитать SKILL.md и references/conversation.md. Новый проект создаётся scripts/create-project.mjs вне каталога репозитория; существующий обновляется scripts/update-project.mjs с сохранением сайта и резервированием. Оба скрипта принимают абсолютный путь проекта; create поддерживает --into-empty, update — --agent codex|claude.

create-project по умолчанию устанавливает полную базу в .agents/skills/site-fast. Для Claude Code перенести созданную папку целиком в .claude/skills/site-fast до дальнейшей установки. Пользовательский AGENTS.md сохраняется.

Зависимости устанавливаются в проекте, а не в репозитории: Node.js >=22, npm, npm ci и npx playwright install chromium. Проверка — node tools/check-env.mjs . Материалы и дальнейший диалог — по SKILL.md. Публикация — по references/deployment.md после явного разрешения конкретного запуска.

## Состав

- scripts/ — создание, обновление и проверки проекта;
- references/ — рабочая методика агента;
- assets/ — шаблоны проекта, материалов, сервиса форм и размещения;
- agents/ — метаданные скилла;
- tests/ — локальные регрессионные проверки.

Для теста обработчика сначала установить его lock-зависимости в assets/form-service. Затем node --test tests/design-inputs.test.mjs tests/deployment.test.mjs. Тесты не публикуют сайт и не отправляют реальные письма.

SHA256 файлов — MANIFEST.sha256. В репозиторий не входят клиентские проекты, личные материалы, доступы и платные пакеты.
